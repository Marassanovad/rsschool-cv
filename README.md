# CV — Darya Marassanova

Personal CV and portfolio website built as part of the **Rolling Scopes School × EPAM** program.

## About the project

This project is a responsive single-page CV developed with **React** and **TypeScript**.

It presents my professional experience, education, skills, projects, and contact information.

The website supports:

- English and Russian languages
- Responsive design
- Smooth navigation between sections
- Project showcase
- Social and contact links

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- i18next / react-i18next
- Lucide React
- ESLint
- Prettier
